# kutty-jarvis

A free, open-source AI buddy that lives on your PC. Press a hotkey, ask out loud, and it looks at your screen, answers by voice, and moves a cursor to the thing it is talking about.

> Status: early development. Nothing is usable yet.

## Goals

- **Free to run.** Local models (Liquid AI LFM) work out of the box on a CPU-only laptop. Cloud API keys are an optional upgrade.
- **Private.** The screen is captured only when you press the hotkey. Nothing is stored or sent anywhere unless you add a cloud key. No telemetry.
- **Provider-agnostic.** Swap models, speech-to-text and text-to-speech freely.
- **Windows first**, with macOS and Linux to follow.
