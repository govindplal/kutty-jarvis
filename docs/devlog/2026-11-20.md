# Devlog 2026-11-20

Day one: from "build this thing but free and better" to a public repo, ground rules and a first measured result.

## Timeline

- **Research.** Read the HeyClicky site, the MIT-licensed original and a handful of clones. Key realisation: the core loop is simple and public; the gap is a genuinely free, local-first version. Wrote it up in [research 0001](../research/0001-heyclicky-and-open-source-landscape.md).
- **The `rea` tool.** Considered using it to reverse engineer the closed app, then decided against it: terms-of-service risk and the danger of tainting an MIT project. See [ADR 0002](../adr/0002-build-from-scratch-clean-room.md).
- **Decisions from the owner:** build from scratch, Windows first, API keys plus local Liquid AI models, buddy first, name `kutty-jarvis`. Framework left to us: Tauri v2 ([ADR 0003](../adr/0003-tauri-over-electron-and-python.md)).
- **Repo setup.** Private GitHub repo, MIT licence, Conventional Commits enforced by commitlint and husky, branch-name check on push ([ADR 0006](../adr/0006-conventional-commits-and-trunk-based-flow.md)).
- **First spike.** Can a 1.6B vision model on CPU point at things? Not accurately. See [finding 0001](../findings/0001-vision-grounding-lfm25-vl-cpu.md) and [ADR 0005](../adr/0005-ui-automation-first-pointing.md).
- **Going public.** GitHub refuses branch protection on private repos on the free plan, so the repo went public (it was always going to be) and `main` was protected.

## Things that went wrong (useful for the blog)

1. **Our own commit hook rejected our own commits, twice.** Commit bodies with long lines failed the 72-column rule. Once with the tooling commits, again with the first batch of ADRs. Fix: a small helper that wraps bodies automatically. Lesson: when you enforce a rule on an AI agent, give it the helper, not just the rule.
2. **A silently truncated model download.** The 583 MB projector file stopped at 439 MB with no error. `llama-server` failed with a baffling "failed to seek for tensor" message. Fix: compare file size with the server's `Content-Length`, then resume with `curl -C -` in a retry loop. Lesson: always verify large downloads.
3. **Missing `jq`.** Piping an API call into `jq` on a machine without it made the branch-protection request appear to fail when it had not been sent. Lesson: do not pipe the write call into a tool you have not checked exists.
4. **Hypothesis written late.** The spike's hypothesis was only written down after the first runs. The finding template now says to write it before running.

## Surprises

- The model answered "where is Settings?" with the same point it gave for three other buttons. That looks like a learned default, not perception.
- Halving the image width cut latency about 3x while costing roughly one hit out of eight.
- Thread count barely mattered; image token processing is the bottleneck.

## Numbers worth remembering

- LFM2.5-VL-1.6B Q4_K_M on an i7-10750H: about 35 prompt tokens/s, 30 generated tokens/s.
- 1280x720 screenshot = 810 prompt tokens, about 24 s. 640x360 = 263 tokens, about 7.6 s.
- Best raw grounding: 4/8 hits, 66 px mean error.
